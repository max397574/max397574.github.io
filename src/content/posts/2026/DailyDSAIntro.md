I'm interested in data structures and algorithms and like learning about new
things in that field. Because just learning stuff about myself without really
having a goal and because I want to write things down anyways I had the idea
that I could share these things in form of a blog.

This is the first thing I'm posting here, in the future I might also write about
some other things.

# What to expect

## Praxis-oriented writing on DSA

My goal is to mostly cover data structures and algorithms which actually have
practical use cases. That means I (most often) won't e.g. write about a
randomized algorithm with linear expected runtime, but rather about one with
like $O(n \log n)$ without some huge constants.

One of the reasons I'm interested in this topic is competitive programming.
Because of that I'll focus more on efficient and fast implementations rather
than "nice" ones which are in line with all the best-practices.

For most things (I actually don't yet see a reason why not for everything) I'll
be using Rust. Though nearly everything should be mostly language independent
and the Rust code we write shouldn't be too hard to read.

## Regular Posts (hopefully)

As one could expect from the name of the series (_daily_ DSA) I'll try to
publish new things daily. Though at some point that will obviously end. Just so
you can't say I didn't tell you.

## No-AI

I don't want to have any AI written text or code here.

# What to not expect

## Particularly good writing

I'm non-native English speaker and wouldn't consider myself an experienced nor a
good writer. So don't expect a really good or errorless (_is that a word?_)
writing style. That I didn't yet set up good spell checking certainly also
doesn't help.

## An organized order

I'm just writing about what I feel like and have the time for. So I might talk
about some things which I haven't previously talked about. If that should
happen: Most (all actually) of the things here you can easy research yourself on
e.g. Wikipedia, GeeksForGeeks or with your LLM of choice.

I'll try to reference old materials (gotta figure out how links even work here)
as I go along, so if you're reading this at a later point in time there actually
might be a nice structure.

# Rules

## Scheduled Posts

If someone didn't expect this, I got a sometimes quite busy life. Therefore I
(will try to) schedule posts for future dates.

## _New_ Topic Daily

I consider e.g. variations of data structures which add new functionality
something new and therefore worthy of it's own day. What exactly falls under
this category is defined by me.
